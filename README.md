# Stock Chala – Aplicación web

Proyecto listo para publicar en GitHub Pages.

## Archivos
- `index.html`: interfaz web para vendedores.
- `data.json`: datos de stock exportados desde `STOCK_APP / Saldo Actual`.

## Publicación
1. Crear un repositorio público en GitHub, por ejemplo `stock-chala`.
2. Subir `index.html` y `data.json` a la rama `main`.
3. En GitHub: Settings → Pages → Deploy from a branch → `main` → `/root`.
4. GitHub generará una dirección `github.io`.

## Actualización
Cuando cambie el Excel, se debe volver a generar `data.json` con los datos actuales y reemplazarlo en GitHub. La página no necesita cambiar.

## Modelo
La interfaz está inspirada en el sistema Stock CDA Camaná, cuyo repositorio público usa `index.html`, `data.json` y una rutina de actualización. No se copiaron sus datos.
